# STALZONE Bot

Discord-бот для сообщества игры STALZONE: распознаёт предметы на скриншотах инвентаря, считает их стоимость и ведёт сервисы скупки ресурсов, бустов, репутации Арсена и прокачки убежища через тикет-каналы.

English readme: [README.md](README.md)

## Как это работает

1. Игрок отправляет скриншот инвентаря в канал (просто картинкой или с командой `!скан`).
2. Бот сравнивает области скриншота с эталонными иконками из папки `templates/` (шаблонное сравнение OpenCV - быстро, бесплатно, работает офлайн).
3. Количество считается двумя способами сразу: несколько одинаковых иконок = несколько предметов, плюс цифра стака в углу иконки распознаётся через OCR (Tesseract).
4. Цены берутся из JSON-прайсов и могут автообновляться с официального аукциона EXBO или синхронизироваться с Google-таблицей.
5. Бот отвечает отформатированным списком: наименование - количество - цена - сумма.

## Ключевые фичи

- **Сканер инвентаря** - распознаёт предметы на скриншотах, OCR цифр стаков, отчёт с ценами.
- **Заказ бустов** - `/buy_boost` создаёт приватный тикет; игрок пишет заказ свободной формой (каждая позиция с новой строки), бот мгновенно считает сумму, понимает синонимы и промокоды со скидками (SQLite).
- **Скупка ресурсов** - тикет `/sell_resources`: скриншот превращается в смету по актуальным ценам скупки.
- **Другие сервисы** - `/sell_other` (прочие вещи), `/buy_reputation` (репутация Арсена, цена за 1к репы), `/buy_upgrade` (навыки убежища, цена пропорционально оставшимся уровням, уровень можно считать OCR со скриншота), `/calc` (калькулятор мякоти).
- **Автоцены с аукциона** - минимальные цены лотов с API EXBO (OAuth client_credentials или статичный токен) каждые `AUTO_UPDATE_HOURS` часов; ручная цена (`!цена`) перекрывает аукцион для предмета.
- **Синхронизация с Google-таблицей** - цены бустов и ресурсов подтягиваются из таблицы каждые `SHEETS_SYNC_HOURS` часов или по `!синк_цен`; официальные иконки предметов скачиваются автоматически как шаблоны распознавания.
- **Объявления об изменении цен** - изменения копятся и публикуются в отдельный канал по `!обновить_ценник` или после авто-синка.
- **Админ-инструменты** - команды управления ценами, импорт цен из .json/.csv, рассылка участникам с подтверждением, статистика реферальных промокодов.

## Стек

Python 3.10+, discord.py, OpenCV, NumPy, pytesseract (Tesseract OCR), aiohttp, requests, gspread, SQLite.

## Установка

1. Установи **Python 3.10+**.
2. Установи зависимости: `pip install -r requirements.txt`
3. Установи **Tesseract OCR** (нужен только для цифр стаков и уровня убежища):
   - Windows: установщик с https://github.com/UB-Mannheim/tesseract/wiki
   - Linux: `sudo apt install tesseract-ocr`
   - Если OCR не нужен - поставь `USE_OCR = False` в начале `bot.py`.
4. Создай бота на https://discord.com/developers/applications:
   - New Application -> Bot -> скопируй **токен**;
   - включи **Message Content Intent** (Bot -> Privileged Gateway Intents);
   - пригласи бота с правами на чтение/отправку сообщений, вложения и **Manage Channels** (нужно для тикетов).
5. Заполни настройки в начале `bot.py` (см. ниже).
6. Запуск: `python bot.py` - в консоли должно появиться, что бот запущен.

## Настройка

Все настройки - константы в начале `bot.py`. Заглушки, которые нужно заполнить:

| Настройка | Что вписать | Обязательно? |
| --- | --- | --- |
| `TOKEN` | Токен Discord-бота (заменить `YOUR_DISCORD_BOT_TOKEN_HERE`) | Да |
| `GUILD_ID` | ID сервера (ПКМ по серверу -> «Копировать ID сервера»; слэш-команды появятся мгновенно) | Очень желательно |
| `CLIENT_ID` / `CLIENT_SECRET` | Из заявки EXBO (Bot Access), для боевого API аукциона | Когда одобрят |
| `API_TOKEN` | Демо-токен из документации EXBO (заменить `YOUR_EXBO_API_TOKEN_HERE`); используется, только если CLIENT_ID/SECRET пустые | Для демо-режима |
| `API_BASE` | Сменить на `https://eapi.stalzone.net` для боя | Когда одобрят |
| `TICKET_MESSAGE` | Заготовленное сообщение, которое бот шлёт в каждый новый тикет | По желанию |
| `FAQ_CHANNEL_ID` | ID канала с частыми вопросами (включает кнопку FAQ в тикетах) | По желанию |
| `TICKET_ADMIN_ROLE` | Имя роли для закрытия тикетов (пусто = право «Управлять каналами») | По желанию |
| `PRICE_NEWS_CHANNEL_ID`, `CHAN_*_ID` | ID каналов для объявлений и привязки слэш-команд (0 = выкл) | По желанию |
| `TESSERACT_CMD` | Путь к tesseract.exe (по умолчанию стандартный; на Linux/Mac - `None`) | Если путь другой |
| `AUTO_UPDATE_HOURS` / `SHEETS_SYNC_HOURS` | Интервалы автообновления аукциона / синка таблицы (0 = выкл) | По желанию |
| `MATCH_THRESHOLD` | Точность распознавания: 0.85 по умолчанию; 0.80, если не находит, 0.90 при ложных срабатываниях | Только при проблемах |

### Файлы, которых нет в репозитории (создай сам)

- **`credentials.json`** - ключ сервисного аккаунта Google для синка с таблицей. Google Cloud Console -> создай сервисный аккаунт -> скачай JSON-ключ -> включи Google Sheets API -> открой доступ к таблице для `client_email` из ключа. Таблица должна называться `ДЛЯ ЛЮБИМЫХ ПРОГРАММИСТОВ`, листы - `ЦЕНЫ БУСТОВ` и `ЦЕНЫ РЕСУРСОВ` (пары «название - цена» в диапазоне C2:P24). Файл секретный - он в `.gitignore`, не коммить его.
- **`Base.db`** - база промокодов (SQLite). Необязательна: без неё промокоды просто отвечают «не найден». Создать:

  ```sql
  CREATE TABLE Referal (
      Youtuber TEXT NOT NULL,
      Link     TEXT,
      Num      INTEGER,
      discount INTEGER,
      date     INTEGER,
      PRIMARY KEY (Youtuber)
  );
  ```

- **`resources.json`** и **`price_news.json`** - создаются сами при работе (синк таблицы / объявления).
- **`templates/`** - эталонные иконки для распознавания. Нарежь иконки предметов с именами файлов = ключи прайса (`katalizator.png`, ...) или дай боту скачать официальные иконки автоматически при синке таблицы. Подпапки - несколько вариантов иконки одного предмета.

## Примеры использования

Для игроков:

| Команда | Описание |
| --- | --- |
| `!скан` + картинка (или просто картинка) | Распознать предметы и выдать отчёт с ценами |
| `/buy_boost` | Открыть тикет на покупку бустов |
| `/sell_resources` | Открыть тикет скупки ресурсов (скриншот -> смета) |
| `/sell_other`, `/buy_reputation`, `/buy_upgrade`, `/calc` | Другие сервисы |
| `!прайс`, `!бусты`, `!репы`, `!апгрейды` | Показать прайсы |
| `!буст <заказ>` | Быстрый расчёт без тикета |

Для админов:

| Команда | Описание |
| --- | --- |
| `!цена <ключ> <цена>` / `!автоцена <ключ>` | Ручная цена / вернуть автоцену с аукциона |
| `!обновить` | Принудительно обновить цены с аукциона |
| `!синк_цен` | Синхронизировать цены с Google-таблицей |
| `!обновить_ценник` | Опубликовать объявление об изменении цен |
| `!буст_добавить`, `!буст_цена`, `!буст_удалить`, `!синоним` | Управление прайсом бустов |
| `!промокоды`, `!промо_добавить`, `!промо_удалить` | Управление промокодами |
| `!импорт_цен бусты\|предметы\|ресурсы` + файл | Импорт цен из .json/.csv |
| `/broadcast` | Массовая рассылка участникам (с подтверждением) |
| `!закрыть` | Закрыть тикет бустов (пишется внутри тикета) |

## Структура проекта

```
stalzone-bot/
├── bot.py              - весь бот (все настройки - в начале файла)
├── prices.json         - прайс предметов (сканер + аукцион)
├── boosts.json         - прайс бустов (+ синонимы)
├── reputation.json     - цены за 1к репутации Арсена
├── upgrades.json       - цены прокачки навыков убежища
├── item_index.json     - индекс предметов игры (для авто-иконок)
├── requirements.txt    - зависимости
└── templates/          - эталонные иконки для распознавания
```
